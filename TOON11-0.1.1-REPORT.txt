11툰 0.1.1 수정 — 2026-11-26
사용자 기기에서 HTTP200 응답이 브라우저 확인 페이지로 판정되어 Discover가 비어 있었음.
0.1.0은 본문 어디든 challenge-platform/cf-chl 문자열이 있으면 거부했으므로 정상 페이지의 보안 스크립트에도 오탐 가능.
0.1.1은 정상 목록/상세/회차/이미지 배열이 있는 응답을 스크립트 이름만으로 거부하지 않음.
정상 콘텐츠가 없고 실제 확인 화면 제목 또는 폼이 있는 경우에만 확인 페이지로 판정. 401/403/429 등 HTTP 오류 처리는 유지.
이는 응답 판정 수정이며 사이트 보호 기능 변경이나 인증 우회가 아님.
지구본: SDK 0.8의 CLOUDFLARE_BYPASS_REQUIRED 기능 선언 추가, getCloudflareBypassRequestAsync 요청에 기본 UA/Referer 적용, 구형 getCloudflareBypassRequest 진입점 추가. 일반 웹뷰 요청만 반환함.
목록/상세/뷰어에 challenge-platform 스크립트가 있어도 수용하는 재현 시험과 실제 확인 폼 거부 시험 통과.
기존 검색/설정/메타데이터/최대1309회차/페이지순서/오류처리 시험 및 타입검사/공식0.8 동시빌드 통과.
sourceID Toon11, 작품/회차ID 유지. SBXH 파일 변경 없음.
앱 실제 응답 원문을 받지 못했으므로 사용자 오류의 직접 원인이 오탐이라고 확정하지 않음. 실제 인증 페이지가 반환된 경우 계속 오류를 표시함.
iPhone 지구본 실행과 Discover 복구는 미검증. PC 실시간 접속은 앞서 ECONNRESET으로 실패한 상태이며 성공으로 주장하지 않음.
