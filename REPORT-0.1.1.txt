Paperback SBXH 0.1.1 / Mangayomi SBXH 0.1.4 — 2026-11-26

회차 제한 원인 및 수정
공개 작품 HTML은 한 페이지 100개, episode-pager의 epage=2... 링크로 다음 목록을 제공한다.
Paperback 0.1.0의 getChapters는 첫 HTML만 파싱했다. 0.1.1은 다음 연속 페이지를 순차 요청하며 마지막까지 수집한다.
총개수 임의 상한 없음. ID 중복 제거, 기존 순서와 ID 보존, active 페이지 검증, 진행 정지/페이지 누락/네트워크 오류 감지.
서버에서 이미지 오류로 비활성화한 회차는 개수 대조에 포함하되 유효 URL을 만들어 내지 않는다.
Mangayomi는 앞서 배포한 0.1.4에 같은 처리가 있으며 이번에 원격 source.js/index.json이 로컬과 일치함을 재확인했다. 정상 코드를 다시 변경하지 않았다.

라이브러리 조사
공식 Paperback-iOS/extensions-default의 0.8 Paperback.ts 및 설치 SDK alpha.38/공식 alpha.47의 SourceManga/MangaInfo를 비교했다.
기존 id/mangaInfo/titles/image 및 Chapter 필수 필드 구조는 일치한다. source ID SBXH, manga ID, chapter ID는 변경하지 않았다.
확인된 결함: 모든 작품의 MangaInfo.hentai가 true였다. 일반 작품까지 성인물로 분류하여 표시 필터에 영향을 줄 수 있다.
작품 장르 라벨을 전달하고 명시적 성인 라벨을 판별하도록 수정했다. 라벨이 없으면 기존 보수적 true를 유지한다.
SourceInfo의 ADULT 등급은 혼합 콘텐츠 소스 등급으로 유지했다. 표시 필터를 비활성화하거나 우회하지 않는다.
status는 공식 0.8 예제의 소문자 형식과 맞췄다.
기기 DB/필터/로그는 확인하지 못했으므로 라이브러리 증상의 직접 원인 및 해결 여부는 아직 확정할 수 없다.
사용자 사진: test에는 SBXH 1작품과 기본 Paperback 설명서 1작품을 추가했고 설명서 카드만 보임. 사진 개수는 갱신 전 상태.

검증
TypeScript 검사 및 공식 0.8 alpha.38 도구 빌드 통과.
양쪽 실제 파서를 실행하는 합성 HTML 시험: 52/99/100/101/112/1309개, 각각 1/1/1/2/2/14회 요청, 전부 통과.
중복, 열람불가 행, 반복 응답, 진행 없음, HTTP503, 마지막 페이지 누락, 페이지 건너뜀, 분류/메타데이터 시험 통과.
Paperback 목록/검색/이미지 코드가 0.1.0과 변경되지 않았음을 확인(줄바꿈 정규화).
이전 Mangayomi 실제 요청 기록: 원피스 총1309=열람가능1306+비활성3(14요청), 112회차(2요청), 52회차(1요청).
이번 서버 재시험은 HTTP403으로 차단됨. 이전 결과를 이번 실시간 성공으로 주장하지 않음.
iPhone 0.1.1 라이브러리 카드, 기존 기록 유지, 미열람 수, 자동 갱신 및 1000회차 이상 표시: 미검증.
