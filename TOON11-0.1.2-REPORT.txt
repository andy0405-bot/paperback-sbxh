11툰 0.1.2 — 날짜/회차 카드 부제
원인: 기존 listing은 title/image만 반환하고 subtitle을 설정하지 않았음.
수정: 웹 카드의 날짜(MM.DD)를 부제로 전달. 제공하지 않는 연도/시각을 만들지 않음.
웹 목록에서 최신 회차가 직접 제공되면 표시. 없으면 이미 수행한 상세/회차 조회에서 받은 첫 회차를 소스 전용 상태에 저장해 재사용.
목록 날짜와 저장 날짜가 다른 경우 과거 회차 번호를 표시하지 않음. 카드별 추가 HTTP 요청 없음.
처음 보는 작품은 날짜만 표시될 수 있음. 상세 또는 회차 조회 후 목록을 갱신하면 수집된 날짜와 일치하는 회차 번호 표시 가능.
날짜 없음/댓글 개수와 구분/캐시 회차/다음날 과거 회차 숨김 시험 통과. 기존 회귀 및 타입 검사/공식0.8 빌드 통과.
브라우저 최신 목록에서 MM.DD 표시를 직접 관찰했으나 자동 HTML 저장 도구 오류로 원문 저장은 완료하지 못함. Node 및 내장 브라우저 접속은 연결 초기화로 실패.
iPhone 카드 부제 렌더링 미검증. SBXH 소스/날짜/회차 코드는 변경하지 않음.

SBXH 라이브러리 진단은 미해결. 원피스와 마을사람A의 실제 상세 HTTP200과 정상 ID/제목/표지/hentai=false는 이전 확인됨.
아이폰 DB의 저장된 작품 및 source 참조를 읽을 수 없어 라이브러리 카드 부재의 직접 원인을 확정하지 못함.
근거 없이 등급을 변경하거나 기존 작품을 삭제하는 처리는 하지 않았음.
