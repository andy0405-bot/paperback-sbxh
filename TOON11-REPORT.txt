11툰 한국어 — Paperback 0.8 시험판 0.1.0
저장소: https://github.com/andy0405-bot/paperback-sbxh
Repository Base URL: https://andy0405-bot.github.io/paperback-sbxh/0.8/

프로젝트 및 재사용
기존 @paperback/types/toolchain 0.8.0-alpha.38, TypeScript 4.9.5, cheerio 및 GitHub Pages 워크플로를 재사용했다. 0.9 API나 새 의존성을 추가하지 않았다.
SBXH 소스를 가져와 덮어쓰거나 수정하지 않았다. 원격 0.1.2와 줄바꿈 정규화 후 일치한다.
독립 source ID Toon11, 이름 11툰 한국어, 버전0.1.0. 작품ID는 숫자 is, 회차ID는 bo_table:wr_id. 제목/도메인과 독립적이다.
기존 SBXH 라이브러리나 기록을 직접 읽거나 변경하는 코드는 없다. 실제 iPhone 데이터 유지는 미검증이다.

공개 소스 조사
Keiyoushi extensions-source src/ko/toon11/Toon11.kt 및 Filters.kt 확인. Apache-2.0 라이선스.
선택자·일반 페이지 주소·JSON 이미지 목록 처리 개념을 TypeScript로 이식했다. includes에 라이선스 및 출처/수정 고지 동봉.
Mangayomi kodjodevf/mangayomi-extensions와 kashrtx/yomi-extensions의 공개 트리에서는 11toon/toon11 경로를 찾지 못했다. 모든 저장소에 없다고 단정하지 않는다.
원본: https://github.com/keiyoushi/extensions-source/tree/main/src/ko/toon11

지원 구현
최신 업데이트 작품, 인기 작품, 제목 검색과 페이지 이동.
작품 h2.title, img.banner, 작가/장르/소개/분류 파싱.
회차 #comic-episode-list 및 button onclick의 일반 링크 파싱. 페이지 끝까지 순차 조회, 중복 제거, 기존 사이트 순서 유지.
동일 작품 확인, 페이지 번호·진행 중단·반복 검증. 임의 전체 개수 제한 없음.
회차의 img_list JSON 배열을 실행 없이 파싱하고 원래 순서의 HTTPS 주소 반환.
설정: 11툰 소스 설정의 기본 URL. HTTPS origin만 허용하며 작품 및 회차 ID는 변경하지 않는다.
일반 웹뷰 진입 훅 제공. 401/403/429/기타HTTP/확인페이지/연결실패를 구분한다.

검증
TOON11-TEST-RESULTS.json: 실제 확장 코드를 실행하는 합성 HTML 시험으로 검색/목록/상세/설정/회차/이미지 순서/오류 분류 통과.
회차 1/99/100/101/1309개, 순차 요청 수와 마지막 회차, 페이지 반복 및 네트워크 실패 처리 검증.
기존 SBXH 회귀 검사 통과. TypeScript 검사 및 두 확장 동시 번들 성공.
실제 PC Node 요청: update.spotv24.com의 홈과 최신 목록, 사이트가 안내한 11toon1.com에 ECONNRESET. curl도 연결 초기화, HTTP000. 응답 상태나 본문을 받지 못했으므로 403 또는 인증 문제라고 단정하지 않는다.
웹 검색 도구의 공개/캐시 문서에서는 최신·인기 목록 및 원피스 상세 텍스트를 확인했으나 이것은 앱 요청이나 이미지 다운로드 성공 증거가 아니다.

제한/미검증
현재 PC 네트워크에서 실시간 목록/검색/상세/회차/이미지 다운로드를 검증하지 못했다. iPhone 설치 및 모든 화면도 미검증.
별도 신규 등록순 주소는 확인되지 않아 임의 엔드포인트를 추가하지 않았다. 최신 업데이트 및 인기 두 섹션 제공.
원본 소스의 이미지 미러 자동 재시도는 이식하지 않았다. 우선 일반 img_list만 제공한다.
사용자 기본 URL 변경은 공식 안내를 확인한 주소에 한정해 사용해야 하며 자동 주소 탐색·프록시·인증 우회는 없다.
보호된 회차, 유료 구매/인증, 실행형 이미지 암호화 등은 지원하지 않는다.
사이트의 자동화 허가 및 콘텐츠별 제공 권한은 확인되지 않았다. 확장 코드 라이선스가 사이트 콘텐츠 열람 권한을 부여하지 않는다.
정당한 권한이 있는 일반 콘텐츠만 지원하며, 서버가 제한하는 응답은 실패로 처리한다.

아이폰 확인
기존 저장소를 갱신하여 11툰 한국어 0.1.0을 별도로 설치한다. SBXH는 삭제하지 않는다.
먼저 지구본으로 일반 접속 여부를 확인한 뒤 최신/인기/검색, 작품 상세, 100개 이상 회차, 첫/중간/끝 이미지 순서를 확인한다.
실패 시 확장 버전과 오류 문구를 기록한다. 현재 연결 실패를 정상 작동으로 보고하지 않는다.
